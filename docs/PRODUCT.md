# PLNA Smart Map — продукт

© 2026 Smart Map from PLNA · версия приложения **0.2.0**

## Что это

Мобильное приложение для **списка покупок + маршрута по залу**.  
Покупатель дома или по дороге собирает заметку с товарами (вес/объём), в магазине открывает карту и идёт по маршруту к стеллажам.

Часть экосистемы **PLNA**: один C++ движок карты, общая модель данных магазина, несколько приложений поверх одного ядра.  
См. [ARCHITECTURE.md](ARCHITECTURE.md) и [WHY_CPP.md](WHY_CPP.md).

## Для кого

| Кто | Зачем |
|-----|--------|
| Покупатель гипермаркета / супермаркета | Быстрее найти товары, не бродить по залу |
| Семья / совместные покупки | Заметка на телефоне, офлайн после синхронизации |
| Иностранный гость | Языки: русский, английский, белорусский |
| Сеть магазинов (позже) | Единый каталог + план зала из одного Firebase |

## Когда используют

1. **До визита** — создать заметку, найти товары в каталоге, указать «1л ПЭТ / 500г / 3кг».
2. **В магазине** — выбрать магазин, открыть карту, идти по маршруту; опционально «Иду» для точки «я».
3. **Офлайн** — каталог и карта уже в Room после первой синхронизации.

## Демо-доступ

Одно поле: **телефон (≥9 цифр)**. Профиль только на устройстве, без облачной синхронизации списков.  
Это не продакшен-аккаунт — так и подписано в UI.
