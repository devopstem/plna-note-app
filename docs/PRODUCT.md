# PLNA Smart Map — продукт

© 2026 Smart Map from PLNA

## Что это

Мобильное приложение для **списка покупок + маршрута по залу**.  
Покупатель дома или по дороге собирает заметку с товарами (вес/объём), в магазине открывает карту и идёт по маршруту к стеллажам.

Часть экосистемы **PLNA**: один C++ движок карты, общая модель данных магазина, несколько приложений поверх одного ядра.

## Для кого

| Кто | Зачем |
|-----|--------|
| Покупатель гипермаркета / супермаркета | Быстрее найти товары, не бродить по залу |
| Семья / совместные покупки | Заметка на телефоне, офлайн после синхронизации |
| Иностранный гость | Языки: русский, английский, белорусский |
| Сеть магазинов (позже) | Единый каталог + план зала из одного Firebase |

## Когда используют

1. **До визита** — создать заметку, найти товары в каталоге, указать «1л ПЭТ / 500г / 3кг».
2. **В магазине** — выбрать магазин (или вручную, если GPS/интернет недоступны), открыть карту, идти по маршруту.
3. **Офлайн** — каталог и карта уже лежат в Room на телефоне после первой синхронизации.

## Что видит пользователь

| Экран | Содержание |
|-------|------------|
| Splash | Логотип Smart Map, название, слоган |
| Главная | Аватар + имя (гость или вошедший) |
| Списки | Список заметок, создание, открытие |
| Заметка | Название + поиск товара + список позиций + «На карте» |
| Карта | План зала (C++ draw list) + маршрут от якоря Вход/Кассы + лицо стеллажа + компас |
| Профиль | Вход (телефон/код), аналитика, магазин, тема, язык, «О нас» |
| О нас | Описание, шаги, версия **MVP 0.1**, © Smart Map from PLNA |

## Вход (без пароля)

Один поле: **телефон (≥9 цифр)** или **пригласительный код** (`PLNA`, `GIPPO`, `1234`, `NOTE`).  
Чужие списки покупок секретны не критично — пароль не нужен. После входа показывается простая аналитика (число списков/товаров, активный магазин).
