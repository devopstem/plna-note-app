## MVP 0.1.0 — 2026-10-16

Карта магазина стала «живой» для MVP: маршрут от реального якоря, лицо стеллажа, компас, без обещания GPS внутри зала.

### Карта и навигация

- **Якорь «Я здесь»**: переключатель **Вход / Кассы** (не GPS). Старт маршрута берётся из маркеров `entrance` / `cash_register` в JSON плана; если маркеров нет — из `layout.entranceSide` / `cashSide`.
- Убран захардкоженный старт `(15, 25)`.
- Зелёная точка старта на плане + подпись якоря.
- Выбор якоря сохраняется в `SharedPreferences` (`plna_map`).
- UI: заметка и якорь в **одной карточке**; Вход/Кассы — сегмент на всю ширину.

### Стеллаж и товар

- Подсветка **целевого стеллажа** (рамка + id), не только точка товара.
- Bottom sheet **«лицо стеллажа»** (полки / bay) при фокусе на товар из заметки.
- Маршрут и подсветка завязаны на ближайший некупленный товар заметки.

### Ориентация в зале

- Буквы **С / В / Ю / З** по краям плана (с учётом `bearingDegrees`).
- Мини-компас в углу экрана (север всегда «вверх» относительно здания).

### Производительность / отрисовка

- `StoreMapView`: hardware layer, стиль гондол/маршрута, zoom / rotate / fit.
- Native draw-list + тонкий маршрут в `plna_core` (без смены стека UI).

### Данные

- Демо-каталог (`demo_catalog.json` + `DemoCatalog`) для лица стеллажа.
- Package: `by.smartplanogram.plnanote`.

### Честно пока нет (следующие уровни)

| Уровень | Статус | Суть |
|---------|--------|------|
| 1 — якорь входа/касс | **сделано в 0.1** | тап «я здесь» → маршрут |
| 2 — PDR (шаги + компас) | не сделано | приблизительное «я» без интернета |
| 3 — BLE-маяки | не сделано | точность ~2–3 м, B2B с сетью |

Точка «я» **не двигается** по залу, пока идёшь — только якорь старта.
