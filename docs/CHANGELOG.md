## 0.2.0 — демо-ready + PDR + Home

### Продукт / UX

- **Главная**: Material 3 hero, магазин, плитки Списки / Карта / Покупки, сводка
- **PDR «Иду»**: шаги (hardware или акселерометр) + компас; «Я здесь» долгим тапом
- **Мои покупки**: локальная аналитика (Room `purchase_events`)
- **Списки**: пустое состояние с CTA
- **Вход**: честный **демо-доступ** (телефон на устройстве, без облака и без кодов на экране)
- **Магазины**: разные подписи снимков карты (не три одинаковых «Гиппо МОМО»)
- **Поиск**: только каталог магазина из Room (демо-SKU не в выдаче)
- Карта: спокойные тексты PDR без «lab»-формулировок

### Платформа / безопасность

- Material 3 light/dark, accent вместо фиолетовых кнопок
- HTTPS only (`network_security_config`, `usesCleartextTraffic=false`)
- Release: R8 minify + shrinkResources + ProGuard keep JNI/Room/Firebase
- Backup / data extraction rules
- Версия `0.2.0` (versionCode 4)

### Документация

- Обновлены README, ARCHITECTURE (чертежи), **WHY_CPP**, GITHUB
